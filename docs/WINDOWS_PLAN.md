# YomiLens Windows 开发规划

更新：2026-09-28。状态：首版已进入实现与打包验证，最新进展和实际选型见 WINDOWS_HANDOFF.md；下文保留原规划与验收标准。

## 目标与默认范围

开发独立 Windows 桌面悬浮工具：框选屏幕日语，在原文附近显示罗马音、平假名或原文对照。沿用 Android 版的简洁配色、默认框选、持续区域边框、专名纠音和离线处理原则。这里的“插件”默认指可独立运行、作用于其他应用上方的桌面工具，无需游戏或浏览器安装扩展。

首版面向 Windows 11 x64，兼顾 Windows 10 2004+；普通桌面窗口和无边框窗口游戏优先。先支持单显示器内框选，再验证多屏不同缩放。以行级邻近标注交付；逐字振假名、可靠竖排、独占全屏、HDR 和高速动态追踪作为后续增强。未知汉字保留并标记不确定，不承诺所有专名和多音字正确。

当前 Android 基线为 0.3.1。保持 Windows 实现在 windows/ 下，避免与 Android 构建耦合。

## 技术路线与先决验证

暂定 Python 3.11/3.12 x64 + PySide6 + ONNX Runtime CPU + RapidOCR + fugashi/UniDic-lite，以缩短首版开发周期。使用独立虚拟环境，不能修改现有 Anaconda 全局依赖。版本在依赖与模型验证通过后锁定，不能直接依赖 latest。这是待原型验证的选型，不是已经安装或测试通过的结论。

- 界面：PySide6 设置页、托盘、框选层、标注层和独立控制条。标注不激活窗口、鼠标穿透；控制条可交互。全局热键包含开始/暂停、重新框选和退出，注册冲突应提示并允许修改。
- 截屏：先用 MSS 验证区域采集，封装 CaptureBackend；若与窗口排除、性能或显示缩放不兼容，再切换 Windows Graphics Capture / Desktop Duplication。不同时维护两套未验证后端。
- 自身窗口排除：对所有可见工具窗口尝试 Win32 SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)，检查返回值，并用真实截屏确认标注不出现、底层文字仍完整。该标志从 Windows 10 2004 起支持，但具体采集链路仍须实测。若失败，先退化为手动单次识别或独立读音面板，并明确显示降级状态；不要用猜测背景色覆盖原文后声称问题已解决。
- OCR：RapidOCR + CPU ONNX 模型，必须显式验证日语支持、字符表、检测与识别模型的配套关系；中文默认模型不能充当已经验证的日语模型。先在自制固定日语测试图上输出文本、置信度和坐标。记录模型来源、版本、SHA256、大小及许可证，再随发行包携带，运行时不下载。
- 读音：fugashi + UniDic-lite 做整句分词。映射其读音/词性字段，与 Android IPADIC 行为逐项比较；从词典字段选择表层读音，不能直接拿词元原形代替屈折后的实际发音。移植 Romaji 的纯逻辑及既有回归用例；保留助词、长音、促音、拨音、外来语与标点规则。
- 专名：沿用 UTF-8 `原文=假名`，最长匹配优先，修改后清空读音缓存。显式导入导出，不自动改写 Android 数据。
- 分发：优先 PyInstaller onedir 便携 ZIP + 启动 EXE，包含模型、词典、Qt/推理运行库和第三方许可。先交付可靠目录包，后续再考虑安装器。用户机不应需要 Python/JDK。

许可检查是打包工作的一部分，特别检查 Qt/PySide、词典与具体模型权重的再分发条款。CPU 为默认，不引入 CUDA、在线大模型或云端 OCR。

## 执行顺序与完成条件

每个阶段结束都留下可运行入口、验证结果和下一步。以下是优先级，不是五小时工期或额度承诺。

### P0：最小技术验证（最高优先级）

1. 检查当前 git 状态、Windows/Python 版本及可用环境；建立 windows/ 与隔离环境。
2. 做静态日语图片 OCR + 读音脚本，输出原文、读音和框坐标；验证包含汉字、假名和标点的整句。
3. 做真实透明窗口与区域截图原型，验证穿透、不抢焦点、自身标注排除及 100%/150% DPI 坐标。
4. 任一核心选型不通过，记录原因和最小替代方案；不先投入 UI 装饰或安装包。

完成条件：两条最小原型可复现，关键依赖和模型可下载并在本机加载。若只能完成这一阶段，必须保留运行命令和失败证据。

### P1：可用闭环

1. 框选 → 截图 → 日语 OCR → 整句读音 → 附近标注。
2. 常显选区边框、开始/暂停/退出、重新框选、三种模式和字号。
3. 设置页保持简洁；托盘可重新打开控制窗口并彻底退出。取消首次框选保持停止，不偷偷全屏识别。
4. 主界面不能被 OCR 阻塞；最多一个分析任务在执行，待处理帧仅保留最新一帧。
5. 暂停、换选区、换模式、显示器变化时递增会话编号，过期结果不能重新绘制。

完成条件：在本机浏览器或测试窗口可读、可点穿、可暂停、可退出；移动文字后不长期显示旧位置；没有可用 EXE 时也有一条明确的源码启动命令。

### P2：稳定性与读音质量

1. 移植 Android Romaji 与 ReadingEngine 测试语料，覆盖长音、助词、符号、空白、未知词、专名最长匹配与缓存失效；允许记录词典差异，不能为了测试变绿删除差异样例。
2. 变化检测、静止降频、相似结果复用和标注寿命：静止画面复用，检测到明显内容移动则撤销过期标注，避免旧标注误导；仅更新必要区域。
3. 明确定义坐标：采集/OCR 使用物理像素，UI 使用 Qt 逻辑坐标；记录显示器原点、DPI、裁剪偏移与缩放。验证副屏负坐标、125%/150% 缩放、跨屏移动及显示器断开。首版可限制选区不能跨屏，并明确提示。
4. 记录采集、OCR、读音、呈现耗时及端到端 P50/P95、CPU/内存、静止/变化画面表现。设置间隔不等于实际延迟；无实测不承诺“实时”。
5. 捕获失败、锁屏恢复、模型缺失、热键冲突、重复启动应可恢复或清楚退出。

完成条件：具名样例、断网测试、连续运行和状态切换有记录；无法实测的设备场景单独列出。

### P3：便携交付

1. 锁定依赖与模型清单，提供环境准备、测试、构建脚本。
2. 打包 ZIP；在未激活虚拟环境的干净路径启动 EXE，并测试带空格和中文路径、断网启动、模型定位与设置持久化。
3. 验证退出释放任务、热键、托盘和窗口；后台不遗留推理进程。
4. 输出 artifacts/windows/ 下版本化包、SHA256、简短使用说明、已知问题和许可说明。未签名状态据实说明。

完成条件：可解压运行，具备启动、框选、暂停和退出流程；实际测试平台与未测项目明确。

## 推荐目录与接口

```text
windows/
  README.md
  pyproject.toml
  src/yomilens_windows/
    app.py              # 程序入口与生命周期
    capture.py          # 物理像素区域截图
    ocr.py              # OCR 适配器，结果包含文本/多边形/置信度
    reading.py          # 词典、人工纠音、缓存
    romaji.py           # 纯文本转换
    pipeline.py         # 单任务调度、变化检测、会话编号
    geometry.py         # 物理像素与 UI 坐标转换
    overlay.py          # 标注层与区域边框
    controls.py         # 设置、控制条、托盘、热键
    settings.py         # 用户设置与词典持久化
  tests/
  scripts/
  models/               # 权重不直接提交；保留模型清单与获取脚本
artifacts/windows/       # 包与验证证据
docs/WINDOWS_HANDOFF.md
```

优先保持模块职责简单，不为未来多后端设计复杂插件系统。用户设置放到用户可写配置目录，不写程序安装目录。默认不保存屏幕截图、OCR 原文或用户阅读内容；诊断仅记耗时、错误和尺寸。测试图片使用自制文本。
