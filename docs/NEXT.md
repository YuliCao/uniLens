# 后续迭代清单

0.2.1 修复了 0.2.0 的旋转缩放竞态，初版回归证据见 TESTING.md。旧 APK 仅作历史快照。下面是超出此次初版修复范围的后续工作。

优先顺序：

1. 0.2.1 通用与 ARM64 APK 已输出；优先进行 vivo 真机验证，尤其 OriginOS 悬浮权限、后台管理与电耗。模拟器结果不能替代真机结论。
2. 图像时序回归：旋转、模式变化、暂停快速往返、裁剪区域和有动画的场景；验证只处理隐藏标注之后的新帧，避免 MediaProjection 排队造成的自识别。诊断命令 `adb shell dumpsys activity service io.github.yomilens/.CaptureService` 不输出屏幕文字。
3. 扩展读音语料，尤其日期、数量词、多音词、姓氏及上下文差异；比较更适合读音输出的离线词典。不能把词典 Viterbi 路径当作语义模型已解决歧义。
4. 逐词位置映射：基于 OCR element / symbol 几何信息和分词偏移建立对应；竖排需要单独的布局策略。
5. 动态画面：比较变化区域裁剪、跨帧跟踪和局部 OCR。先建立稳定的动态测试样例与指标，再选择实现，避免靠猜测声称优化。
6. 端侧性能：后台持续采集的电耗、帧缓冲复用、共享词典实例、低电量降频；实际电池结论必须来自设备测量。
7. 兼容性：Android 8/9 老版本和 Android 16。vivo 手机未接入 ADB，真实 OriginOS 权限与保活尚不能验证。

本机构建使用 `scripts/build.ps1`（隔离 Gradle 用户目录，优先使用已校验下载）。`.tools` 中有 SDK、模拟器、JDK 外部路径配置与构建日志，均不提交到 Git。
